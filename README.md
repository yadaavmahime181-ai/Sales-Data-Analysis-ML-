# Sales Data Analysis and Profit Prediction

This project analyzes sales data and shows useful insights through a Streamlit dashboard. It also uses a machine learning model to predict profit based on product category, sub-category, and sales amount.

## Features
- Sales and profit analysis
- Customer and order insights
- Interactive filters for category, state, city, and gender
- Charts for category-wise and state-wise profit
- Profit prediction using Random Forest Regression

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Streamlit
- MySQL

## How to Run

1. Install the required Python libraries.
2. Make sure the dataset and trained model are in their respective folders.
3. Open the terminal in the project directory.
4. Run:

`streamlit run app.py`

## Project Purpose

The aim of this project is to understand sales performance, explore customer and product data, and use machine learning to estimate profit.
